# Carimbo Digital — MVP

Aplicação web simples para enviar uma NFS em PDF, inserir o carimbo, preencher os campos, adicionar assinaturas independentes de Visto e Atesto, reposicionar o carimbo e baixar o PDF final.

## Testar

Abra `index.html` em um navegador moderno com acesso à internet. As bibliotecas PDF.js e pdf-lib são carregadas por CDN.

O PDF, os dados e as assinaturas são processados localmente no navegador e não são enviados a um servidor.

## Publicar

Publique a pasta em GitHub Pages, Netlify, Vercel ou Cloudflare Pages.

## Limites do MVP

- assinatura visual, sem certificado ICP-Brasil;
- um carimbo por documento;
- sem login, histórico ou armazenamento;
- conexão necessária para carregar as bibliotecas.
